## 🎨 Official Color Palette

### The Synergy Lens (Brand Symbol)
Two interlocking lenses representing the optical clarity of the holding:

* **Primary Lens:** `#334155` (Slate 700) — light backgrounds / `#94A3B8` (Slate 400) — dark backgrounds
* **Accent Lens:** `#0D9488` (Teal 600) — light backgrounds / `#14B8A6` (Teal 500) — dark backgrounds
* **Core Highlight:** `#38BDF8` (Sky 400)

### Typography & Text
* **Wordmark "CLEAR":** `#0F172A` (Slate 900) — light / `#FFFFFF` (White) — dark
* **Wordmark "SOFT":** `#0D9488` (Teal 600) — light / `#2DD4BF` (Teal 400) — dark
* **Domain / Subtitle:** `#0D9488` (light) / `#2DD4BF` (dark)

### Recommended Backgrounds
* **Light Background:** `#FFFFFF` or `#F8FAFC` (Slate 50)
* **Dark Background (Product):** `#0F172A` (Slate 900) or `#020617` (Slate 950)
